# Admission tooling — OFFLINE ONLY.
#
# Never installed on a serving host. The engine does not spawn Python, link it,
# or require it at runtime; these exist to build oracles and profile models.
#
# This is the first requirements.txt in the repo. Every other Python file here
# (tools/qwen_tts_service.py and the two test scripts) is stdlib-only, and that
# stays true — admission is the exception because the conformance oracle is
# defined as "what transformers does".
#
# Install:
#   python -m venv tools/admission/.venv
#   tools/admission/.venv/Scripts/python -m pip install -r tools/admission/requirements.txt \
#       --extra-index-url https://download.pytorch.org/whl/cu128
#
# torch is pinned to a CUDA 12.8 build: the dev box is an RTX 5090 (Blackwell,
# sm_120), which older CUDA builds do not target. CPU-only wheels are sufficient
# for G0/G1 (tiny-random models) but not for G2's fp16 reference pass over real
# checkpoints, so the CUDA build is installed once rather than swapped later.

torch>=2.7.0

# transformers 5.x. Those two ARE the MLA seam fixtures for G4, so the oracle has
# to be able to build them.
